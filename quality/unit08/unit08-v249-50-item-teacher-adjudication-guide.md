## Required teacher approval workflow (no implicit approvals)

1. **Verify source and model.** For each item, inspect the original NBF question and linked V237–V248 source reasoning, confirm original question identifiers and all subparts, and record any incomplete conditions or competing answer paths.
2. **Adjudicate corrections.** Set an explicit teacher resolution of **retain-with-qualified-explanation**, **discussion-only/exclude from grading**, or **independently authored and approved substitute**. Retain the historical publisher question unchanged in the source record.
3. **Authenticate framework placement.** Check the original FBISE assessment framework for exact printed SLO, **Summative/Formative/PBA designation** and cognitive demand. A source-book topic or matching chapter heading alone is **not** permission to score.
4. **Prepare and independently check teacher solutions.** Proper math typography (signs, subscripts, superscripts, units and worked steps), separate source answers from verified alternatives, recalculate every numeric and approve diagrams and subparts. A reviewer should check a second time before any student answer edition.
5. **Explicitly approve publication item by item.** Only after science + framework + teacher answer-key approval and owner release consent should an item be imported to Unit 8 Test Builder; record the specific approved content version and regression result. A merged metadata PR alone never enables release.
