Assignment 1.1 · Estimation

Floating-point operations in a day

Source-pack location: following Worked Example 1.1, before Derived Units.

Try it: Estimate how many floating-point operations a supercomputer could perform in one day if a single operation takes 10−17 s. Give the order of magnitude.
Reveal step-by-step solution
  1. Convert one day into seconds: 24 × 60 × 60 = 86,400 s.
  2. The number of operations is the available time divided by the duration of one operation.
  3. N = 86,400 s ÷ (10−17 s) = 8.64 × 1021 operations.
  4. For an order-of-magnitude estimate, round to approximately 1022 operations.

Answer: N = 8.64 × 1021 operations; order of magnitude ≈ 1022.

Assignment 1.2 · Dimensional analysis

Which expression has acceleration dimensions?

Source-pack location: following the dimensional treatment of the simple pendulum.

Try it: Let x be distance, t time and v velocity. Which expression is dimensionally consistent with an acceleration?
  1. A. v/t2
  2. B. v/x2
  3. C. v2/t
  4. D. v2/x
Reveal answer and dimensional working

Use [v] = LT−1, [x] = L and [t] = T. Acceleration has [a] = LT−2.

OptionDimensionsAcceleration?
A · v/t2LT−3No
B · v/x2L−1T−1No
C · v2/tL2T−3No
D · v2/xLT−2Yes

Answer: D · v2/x.

The dimensional match alone does not prove a complete physical equation; this is a dimensional-consistency exercise.

Assignment 1.3 · Uncertainty

Area and circumference from an uncertain radius

Source-pack location: following the chapter's Example 1.4 on area uncertainty.

Try it: A circle has measured radius r = (10.5 ± 0.2) m. Using π ≈ 3.14, calculate (a) its area and (b) its circumference, including the uncertainty in each value. Apply the elementary percentage-uncertainty rule used in the source pack.
Reveal detailed uncertainty calculation

Given: r = 10.5 m, Δr = 0.2 m, π ≈ 3.14.

  1. Relative uncertainty in radius: Δr/r = 0.2/10.5 ≈ 0.01905, or 1.905%.
  2. Area: A = πr2 = 3.14 × 10.52 = 346.185 m2 ≈ 346.2 m2.
  3. Since A ∝ r2, ΔA/A ≈ 2Δr/r ≈ 0.03810. Thus ΔA ≈ 13.19 m2 ≈ 13.2 m2.
  4. Circumference: C = 2πr = 2 × 3.14 × 10.5 = 65.94 m.
  5. Since C ∝ r, ΔC/C ≈ Δr/r ≈ 0.01905. Thus ΔC ≈ 1.256 m ≈ 1.26 m.

Area ≈ (346.2 ± 13.2) m2. Circumference ≈ (65.94 ± 1.26) m.
